# Dataset Pointers

This repository includes generator-based workloads and pointers to standard suites:

- LP: Netlib LP (MPS) via [Netlib repository](http://www.netlib.org/lp/)
- LP (modern sparse): Mittelmann LP benchmarks and MIPLIB LP relaxations
- QP: Maros-Meszaros QP test set
- Conic/QP-style workloads: portfolio optimization and MPC-like dense classes generated in `benchmarks/generators`

The harness supports local file-based integration for these datasets through adapter scripts.
